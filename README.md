# To-Do List

A to-do list app built with object-oriented JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

🔗 **Live demo:** https://kajrir.github.io/ToDoList/

## Features
- Create projects and add to-dos to them
- To-dos have a title, description, due date and priority
- Edit and delete to-dos
- Data is saved in `localStorage`

## Built with
HTML, CSS and JavaScript (ES6 classes and modules)

## What I learned
- Applying OOP and SOLID principles: separate `ToDo` and `Project` classes and UI logic
- Persisting data in the browser with `localStorage`
